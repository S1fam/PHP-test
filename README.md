Soubor shoppingCart.php obsahuje třídu shoppingCart, která obsahuje položky košíku, slevový kód a finální cenu jako atributy. Dále počítá finální cenu
s ohledem na položky košíku a slevový kupón pomocí funkce calculateFinalPrice() a pomocné funkce applyCoupon(). Funkce getFinalPrice() vrací finální cenu košíku.

Soubor index.php obsahuje ukázku vstupu a jeho zpracování.

Příklad spuštění ve složce: `php index.php`
